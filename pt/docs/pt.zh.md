# PT 账号

在这个页面集中管理你的 PT 站点账号。插件负责刷新登录、每日签到和读取基本数据。插件不下载种子。

## 添加站点

1. 打开 **PT 账号**。
2. 点击 **添加站点**。
3. 填写站点地址，选择站点类型，再填账号和密码。
4. 点击 **检测**，确认站点可以访问。
5. 点击 **保存**。

插件在保存前先验证 Cookie 或 API 密钥。验证失败时，插件不保存任何内容。改正信息后重新保存即可。

:::tip
你也可以粘贴浏览器 Cookie 来代替账号密码。需要浏览器校验的站点用这种方式。
:::

## 刷新登录

在站点卡片上点击 **重新登录**。插件登录站点并保存新的会话。红色标记表示已保存的会话失效。

## 每日签到

在站点卡片上点击 **签到**。插件访问站点签到，然后报告结果。

签到有四种结果：

| 结果 | 含义 |
| --- | --- |
| 签到成功 | 站点确认签到完成。 |
| 今日已签到 | 站点表示今天已经签到过。这算成功。 |
| 未确认 | 登录正常，但站点没有给出结果。插件稍后重试。 |
| 需要处理 | 验证码或浏览器校验挡住了插件。请粘贴浏览器 Cookie 继续。 |

:::caution
**未确认**不是成功。插件会重试，然后如实报告。请到站点确认后再认为签到完成。
:::

## 设置每日计划

每个站点有三个计划项：

- **签到时间窗**：插件可以签到的时间范围。默认不限时间。
- **刷新间隔**：插件读取账号数据的频率。默认 6 小时。
- **最小请求间隔**：同一站点的两次请求之间的停顿。

插件会把任务分散到时间窗内。它每天只发少量请求，不会连续请求。

## 查看账号数据

站点卡片显示当前等级、上传和下载流量、分享率、魔力值和警告。点击卡片可以查看流量历史和签到历史。

空值表示站点没有提供这一项。空值不等于 0。

## 站点需要浏览器时

部分站点会出现验证码或浏览器校验。插件会停下来，要求你提供 Cookie。插件不解验证码。

1. 在浏览器里登录该站点。
2. 从浏览器复制该站点的 Cookie。
3. 在站点卡片上点击 **粘贴 Cookie**。

:::warning
插件不支持代理。需要代理才能访问的站点，本插件无法连接。
:::

## 站点规则

自动签到可能违反部分站点的规则。你需要为添加的每个站点自行遵守其规则。
