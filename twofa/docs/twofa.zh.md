**2FA 保管库**插件保存基于时间的一次性密码（TOTP）账户，例如 AWS、Cloudflare、GitHub 与域名注册商。它按需生成实时动态口令。

在侧边栏打开 **2FA 保管库**，路径为 `/personal/twofa`。

:::note
保管库在写入数据库前加密所有密钥。列表接口不会返回明文密钥。
:::

## 一个保管库，默认私有

2FA 保管库只有一个账户列表。每个账户默认仅创建者可见。

你创建账户，你就拥有它。只有你可以读取密钥、编辑账户或删除账户。

## 把账户共享给工作区

你可以共享自己拥有的账户。共享按账户设置，默认状态为私有。

1. 找到账户卡片。
2. 打开 **共享给工作区**。

工作区成员现在可以看到该账户并读取实时口令。

关闭 **共享给工作区** 即可停止共享。账户恢复为私有。

### 被共享成员可以做什么

- 在保管库列表中看到该账户。
- 读取实时口令。
- 复制口令。
- 校验口令。
- 在卡片上看到 **已共享** 标记。

### 被共享成员不能做什么

- 不能查看密钥明文或二维码。
- 不能编辑账户。
- 不能置顶、删除或导出账户。
- 不能关闭共享。共享只由拥有者控制。

:::caution
共享后，工作区所有成员都能读取实时口令。只共享团队确实需要的账户。
:::

## 添加账户

1. 点击 **+ 添加凭证**。
2. 选择录入方式：
   - **手动录入**：填写名称、签发方、用户名与 Base32 密钥。
   - **Key URI**：粘贴服务提供的 `otpauth://` 链接，系统自动识别字段。
3. 添加标签，便于分组与筛选。
4. 点击 **保存凭证**。

:::tip
置顶账户可以把它固定在列表顶部。只有拥有者可以置顶。
:::

## 读取与复制口令

每张卡片显示当前口令，以及口令失效前的剩余秒数。

点击口令或点击 **复制** 即可复制。

## 查看密钥明文与二维码

只有拥有者可以查看密钥明文。该功能用于绑定备用验证器。

1. 点击账户卡片上的二维码按钮。
2. 弹窗显示密钥明文、`otpauth://` 链接与二维码。
3. 使用验证器应用扫描二维码。

每次查看都会写入审计日志。

## 导入与导出

**导入** 会把账户添加到你的保管库。每行粘贴一条 `otpauth://` 链接。

**导出** 只备份你自己的账户。别人共享的账户属于他人，不会进入你的导出文件。

:::danger
导出文件包含明文密钥。请妥善保管，切勿分享。
:::

## 与 AI Agent 配合使用

Octarq 通过 Model Context Protocol（MCP）提供三个工具。Agent 没有用户身份，只能使用已共享的账户。

- `get_2fa_code(account_name)`：返回实时口令与剩余秒数。
- `list_2fa_accounts(tag)`：列出已共享的账户，不返回密钥与口令。
- `verify_2fa_code(account_name, code)`：报告口令当前是否有效。

Agent 可以代替你登录服务。Agent 永远看不到你的私有账户。

## 审计日志

保管库为以下操作写入审计记录：

- 创建、更新、删除账户。
- 查看密钥明文与二维码。
- 生成与校验口令。
- 共享与取消共享。
- 导入与导出。

每条记录包含操作者、时间与来源地址。
