**2FA 密钥保管库**插件为团队与 AI Agent 提供了安全集中的 TOTP（基于时间的一次性密码）凭证管理中心。无论是 AWS、Cloudflare、GitHub、域名注册商还是各类云平台服务，均可在此统一存储与协同。

相比将双重验证口令分散在个人的手机或浏览器插件中，2FA 保管库在工作区内通过高强度对称加密安全保存种子密钥，并支持按需实时生成与刷新动态口令。

:::note
存储在 2FA 保管库中的所有种子与共享密钥在写入数据库前，均已通过 AES-256-GCM 算法进行加密保护。在常规的列表与查询接口中绝不泄露明文密钥。
:::

## 核心特性

- **实时动态口令生成**：直观展示 6 位或 8 位动态验证码，随倒计时圆环每 30 秒自动刷新并保持时间同步。
- **Agent 原生 MCP 集成**：连接的 AI 智能体（如 Cursor、Claude Code）可在自动化运维任务中调用 `get_2fa_code` 工具直接获取动态口令。
- **Key URI 与二维码便捷导入**：支持粘贴标准的 `otpauth://totp/...` 链接或扫描二维码，系统将自动识别签发机构、用户名、散列算法及轮换周期。
- **无痛团队共享**：团队成员无需再通过通讯工具私下传递密钥种子或重复录入设备，即可共享关键基础设施访问权限。
- **完备的安全审计日志**：对口令生成、明文查看、批量导出以及 MCP 智能体调用的每一次操作均记录时间戳、操作者与来源 IP。

## 管理 2FA 凭证

### 添加新凭证

1. 在工作区侧边栏中点击 **2FA 保管库**。
2. 点击右上角的 **+ 添加凭证**。
3. 选择输入模式：
   - **手动录入**：填写账户名称（例如 `AWS 生产环境`）、签发方、账户邮箱及 Base32 密钥种子。
   - **URI 导入 (`otpauth://`)**：直接粘贴第三方服务提供的配置链接，系统将自动解析字段。
4. 添加标签（例如 `云服务, 核心基建`）以便快速分类与筛选。
5. 点击**保存凭证**。

:::tip
点击凭证卡片上的图钉图标将常用账户置顶，方便高频场景下随时调用。
:::

### 查看与复制动态验证码

凭证卡片上会显示当前生效的数字验证码，采用空格间隔排版（例如 `548 102`）。
- 点击验证码或点击**复制**按钮即可将口令复制至剪贴板。
- 旁侧的倒计时进度环实时显示当前口令在失效前的剩余有效秒数。

### 查看密钥明文与二维码

如需为实体设备或手机 Authenticator App 绑定备用凭证：
1. 将鼠标悬停在对应卡片上并点击**二维码**操作。
2. 弹窗中将展示加密解密后的密钥明文、标准 `otpauth://` 链接以及可扫描的二维码。
3. 每次查看或复制密钥的操作都会在工作区审计日志中留下不可篡改的记录。

:::caution
仅限工作区所有者与获得授权的运维人员查看密钥明文。请定期审查审计日志中的异常访问记录。
:::

## 与 AI Agent（MCP）协同

Octarq 通过 Model Context Protocol（MCP）为外部智能体提供三项核心工具：

- `get_2fa_code(account_name)`：获取指定账户当前的实时 TOTP 动态码及剩余有效秒数。
- `list_2fa_accounts(tag)`：列出保管库中登记的账户名称与标签信息（不泄露密钥与动态码）。
- `verify_2fa_code(account_name, code)`：在安全上下文中校验输入的动态口令是否有效。

当 AI Agent 执行登录控制台或操作域名续费等自动化脚本时，可直接通过上述工具完成二次验证，无需人工介入。
